# Phenol Removal Effficiency Calculator 
## About 
A beginner-friendly Python project that calculates phenol removal efficiency in water using intialand final concentrations.
## Formula
Removal_efficiency (%) = ((initial_concentration - final_concentration) / initial_concentration) * 100
## Tools
- Python
- Jupyter notebook
- VS Code
- GitHub
